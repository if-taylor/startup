## HTML

#### *Interesting things I have learned about HTML*
I can use the live server extension to basically work on my html and see it update in real time.

Head is used for metadata and other info the browser needs, while body is where the actual content of the page goes.

<meta charset="UTF-8"> and <meta name="viewport" content="width=device-width, initial-scale=1.0" /> are helpful for making sure things display properly.
